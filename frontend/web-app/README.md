# Frontend Web

Interface web du projet : Vite + Tailwind CSS.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
```

Le frontend consomme l'API exposée derrière l'API Gateway. Les composants Symfony UX / Twig seront ajoutés côté Core Platform pour les pages rendues serveur, et ce projet Vite servira aux interfaces riches.
